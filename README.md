# Sword Factory (Open-Source Core & AI Agent Blueprint)

**Sword Factory** is an open-source Roblox multiplayer game currently under active development. Beyond serving as a fully functional game, this repository acts as a real-world testbed for integrating autonomous AI coding agents into Luau workflows.

### Key Goals
* **Complete Game Architecture:** Building a scalable game loop including data persistency (via ProfileService), secure client-server networking, and dynamic item state handling.
* **Agentic Development Blueprint:** Providing an open, modular foundation for developers and students to experiment with AI coding agents in Roblox/Luau.
* **Type-Safe Luau:** Benchmarking and implementing strict, type-safe, and real-time optimized Luau server code.
